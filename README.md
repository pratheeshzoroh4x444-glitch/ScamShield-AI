# ScamShield AI

A responsive cybersecurity education prototype that scans pasted messages for common scam warning signs.

## Features
- Local heuristic scan for urgency, upfront fees, sensitive information requests, links, suspicious job/prize language, impersonation and off-platform contact.
- Risk score with matched signals and safety recommendations.
- Sample messages for quick testing; mobile-responsive dark UI.
- No API keys, account system, or backend required.

## Run
Open `index.html` in a modern browser, or enable GitHub Pages in repository Settings → Pages and select the `main` branch and root folder.

## Important limitations
This is a student demo using transparent keyword heuristics, not a trained AI model or a guarantee of fraud detection. Scores are indicative only; low risk does not mean a message is safe. Never paste passwords, OTPs, PINs, or other private details.
